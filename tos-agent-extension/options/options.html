🔑 API Anahtarı Nasıl Alınır?

  • Google Gemini: Google AI Studio üzerinden saniyeler içinde ücretsiz API anahtarı alabilirsiniz.
  • OpenAI: OpenAI Platform sayfasından bir API anahtarı oluşturabilirsiniz.
  • Çevrimdışı / Dahili Motor: Herhangi bir anahtar girmeden doğrudan "Dahili Deterministik Motor" seçeneğini kullanarak testleri ve analizleri yerel olarak çalıştırabilirsiniz.
